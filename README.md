## 👋 Sobre mí

Soy **Edgar Josías Cán Ajquejay**, desarrollador web y estudiante de **Ingeniería en Ciencias y Sistemas** con cierre de pensum en la Universidad de San Carlos de Guatemala.

Desarrollo interfaces y servicios backend combinando **React, Node.js, Python, C#, bases de datos y herramientas cloud**. También trabajo con tecnologías de **IA, agentes y automatización**, utilizando herramientas como ChatGPT, Claude, n8n y Ollama para apoyar el desarrollo y la orquestación de procesos.
